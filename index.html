How to play online

Both players open this same page and enter the same room code. The first player gets White; the second gets Black. Share the room code with your friend.

To enable online rooms, add your Firebase project's configuration in the code where it says PASTE YOUR FIREBASE CONFIG HERE. See the setup notes below.
